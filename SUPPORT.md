# Support

Use [GitHub Discussions](https://github.com/kyambuthia/a-daraja-cli/discussions)
for setup questions and design discussion once Discussions is enabled. Use a
[GitHub issue](https://github.com/kyambuthia/a-daraja-cli/issues/new/choose) for
reproducible bugs or feature proposals.

This is alpha software and support is best effort. Never post consumer secrets,
SDK keys, access tokens, initiator passwords, certificates, callback payloads
containing personal data, or real transaction data.

Report vulnerabilities through the private process in [SECURITY.md](SECURITY.md).
