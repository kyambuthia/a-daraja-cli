# Security Policy

## Supported versions

This project is alpha software. Security fixes are applied to the latest code
on the `trunk` branch; no older release line is supported.

## Reporting a vulnerability

Please report suspected vulnerabilities with a
[private GitHub security advisory](https://github.com/kyambuthia/a-daraja-cli/security/advisories/new)
rather than opening a public issue. Include the affected
version, a minimal reproduction, and the potential impact. Do not include
Daraja credentials, access tokens, private keys, payment data, or other
sensitive information in the report.

We will acknowledge reports, assess the impact, and coordinate a fix before
public disclosure where appropriate.

If the private form is unavailable, do not post exploit details publicly.
Open a minimal issue asking the maintainer to enable private reporting, without
including sensitive details.

## Response targets

- Acknowledgement: within 3 business days.
- Initial severity assessment: within 7 business days.
- Status updates: at least every 14 days until resolution.

These are response targets, not a guarantee. Please allow a reasonable fix and
release window before public disclosure.
